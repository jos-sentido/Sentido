Dirección para el rebrand

  1. Paleta sobria (grafito / acero / blanco) con el rojo #C61F0A como acento, no plano.
  2. Un solo sistema tipográfico (como Kuatro con Manrope): fuerte en títulos, legible en fichas técnicas.
  3. La “M” como monograma geométrico y arquitectónico (a partir del tablero de Jos).
  4. Fotografía real de proyecto con un mismo tratamiento (nivel Honomobo).
  5. Diferenciarnos de Kuatro (su naranja) manteniendo el rojo.
Las muestras marcadas ~aprox. son una referencia visual, no el color exacto del sitio. Modularte y Kuatro tienen colores medidos reales. Para ver cada sitio, entra por los enlaces.
