Sitio Web Modularte · Estructura

El mapa del sitio y el contenido de cada página, en orden. Es la guía para diseñar y programar el nuevo sitio. El objetivo: pasar de un sitio informativo a uno comercial, que lleve a cotizar.

Estructura
Esta estructura define las páginas del sitio y el contenido de cada una: el orden y qué integra cada página. Sirve como guía para el diseño y la programación.
