Sitio web · Estructura y contenido

Sitio Web Modularte · Estructura

El mapa del sitio y el contenido de cada página, en orden. Es la guía para diseñar y programar el nuevo sitio. El objetivo: pasar de un sitio informativo a uno comercial, que lleve a cotizar.

Estructura
Esta estructura define las páginas del sitio y el contenido de cada una: el orden y qué integra cada página. Sirve como guía para el diseño y la programación.

Mapa del sitio · páginas y contenido

Cada página con su descripción y las secciones que llevará. Blog es Fase 2; ZAR y Flotante tienen contenido pendiente (🚧).

Inicio Home

La puerta de entrada: resume todo y empuja a cotizar.

Secciones (en orden)
  • Encabezado (hero): mensaje principal + “Cotizar” + foto real.
  • Configurador Sistema × Aplicación (el “calificador”).
  • Los 5 sistemas (tarjetas con su frase).
  • Soluciones por sector.
  • Por qué Modularte (30 años, respaldo, certificaciones).
  • Proyectos / casos destacados.
  • Cierre + cotización.
